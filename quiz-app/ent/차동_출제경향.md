# 여차동 교수님 출제경향 (2026 이과 시험 11/23 대비)

자료: 2025 이과 기출 25문항(학습지 229–235쪽, 2025년은 여차동 교수님 단독 출제), 2026 형성평가 14문항(11/4 4교시 중간평가 10문항 + 11/5 1교시 형성평가 4문항), 올해 STT(11/4 4–6교시, 11/5 1–2교시).

## 1. 자기 문제를 다시 쓴다 → 「야마 변형」 가설이 맞음
2026 형성평가 14문항 중 6문항이 2025 본인 기출을 거의 그대로 다시 썼다.

| 2026 형성평가 | 2025 기출 | 바뀐 점 |
|---|---|---|
| 11/4 중간평가 8번 (건성 천공 → 고실성형술) | 객15 (CT 진주종 → 고실절개+유양동삭개) | CT 소견 하나만 바꿔 정답을 바꿈 |
| 11/4 중간평가 10번 (AOM → amoxicillin) | 객14 (AOM 진단+항생제) | 묻는 것만 「어떤 항생제」로 |
| 11/4 중간평가 2번 (삼출성 → 환기관) | 객7·객13 (삼출성 → 환기관) | 나이·병력만 바꿈 |
| 11/5 형성평가 2번 (돌발성 난청 증례) | 객10 | 거의 같음(방향 표시만 뺌) |
| 11/5 형성평가 1번 (청력저하 없는 어지럼 = 전정신경염) | 객5 | 같음 |
| 11/5 형성평가 4번 (1-3-6) | 객18 | 같음 |

→ 시험도 **2025 본인 문제 + 형성평가를 조건 하나 바꿔(좌우·CT·어지럼 유무·나이) 다시 낼** 가능성이 가장 높다.

## 2. 형식
- 객관식 약 25문항(STT 11/5), 5지선다, 「옳은/틀린 것」 하나 고르기.
- 증례형(나이·성별·병력·검사 → 진단/치료/예후)이 60% 이상.
- 청력도·고막 사진·안진 판독이 30% 안팎. 2025: 청력도 4, 고막·이개 사진 3, 그림 2. 「빨강 오른쪽·파랑 왼쪽, 일부러 방향 안 주고 낼 수 있음」.
- 「야마 말고 새로 내되 쉽게, 중요한 게 중요한 거」. 두개저 수술법은 「절대 안 냄」.

## 3. 범위
- 2025엔 전 범위(이은정 범위 약 12, 여차동 범위 약 13). 11/4 중간평가도 이은정 범위(구조·청력검사·중이염)를 냄.
- 「자기 범위에서만」이면 아래 여차동 범위가 핵심이고, 이은정 범위는 2025·형성평가에서 본인이 낸 주제만 보면 된다(만성 중이염 수술, 삼출성 환기관, AOM amoxicillin, 청력도 판독, 검사 짝짓기).

## 4. 1순위 주제 (STT에서 「시험」·「꼭」이라고 한 것)
- 돌발성 난청: 정의 3·3·30, 필수 검사 PTA + ABR/MRI, 스테로이드, 예후 인자, 1/3 법칙.
- 메니에르병: 진단 기준(probable/definite), 내림프수종, 저음역 변동성 난청, gentamicin, 급성기 전정재활 제외.
- 만성 중이염·진주종: 「시험 내기 좋은 병」, CT로 수술 범위 결정.
- 4대 감각신경성: 노인성 기준, 이독성(OAE·이뇨제 상승), 소음성(C5 dip, 90 dB 8시간), 돌발성.
- 이경화증: 「시험 문제 제일 내기 좋죠」, Carhart notch.
- 전정신경염 증례: 「문제를 낼 때 이렇게 많이 내죠」, 병측 반대 자발안진.
- BPPV: 「left/right·lateral/posterior는 시험 내기 좋겠다」, Epley/barbecue.
- 1-3-6: 「꼭」.
- 인공와우 경로: 후고실개방술 → 정원창. 「꼭」.
- 안면신경 ENoG: 1–2주, 90%. 「이거는 꼭」. 이마 주름으로 중추/말초 구분.
