## 파일
| 파일 | 역할 |
|---|---|
| `app.html`, `mk.py` | 정신의학 앱과 같은 템플릿/빌더(`mk.py` 여러 개 고르기에 「고르세요」 추가) |
| `build_ent.py` | 모듈 모아 빌드. MODS(티야)·YMODS(야마)·YSEC(구역→수업)·YSRC(근거)·PRE(수업 전)·PREFAM(묶음 단위로 수업 전 보내기) |
| `q1_struct.py` … `q8_fn.py` | 티야. 튜플 `(영역, 키, 문제, [선지5], 정답번호, 해설, [선지별해설5], 근거)` – 정답은 1번 자리에 쓰고 빌드에서 섞음 |
| `fix_choices.py`, `fix_choices2.py` | 길이로 정답이 티 나지 않게 다시 쓴 선지(FIX, 원래 순서) |
| `y_*.py` | 야마. 튜플 `(구역, 묶음, 연도, 번호, 문제, [선지], [정답], 학습지 해설 요약, [메모], 출제교수)`. 문제·정답 None = 앞 카드와 같은 문제(합침), 문제만 None = 문제·선지는 같고 정답 다른 해(따로 카드). 정답 [] = 확인 필요(채점 X), 선지 [] = 주관식 |
| `yexp_ent.py` | 🎓 올해 수업 기준(STT) – 묶음별 CLS / 카드별 EXP |
| `yimg_ent.py`, `img/`, `crop.py` | 그림 문항: 카드키 → 학습지 쪽에서 자른 그림 |
| `tyb.py` | 📌 티야방 표시 |
| `tq_tyb.py` | 티야방 내용을 문제로 만든 티야(TQ={수업 모듈:[튜플]}, 근거가 「티야방 …」이면 자동 📌) |
| `NOTES_src.md` | 자료(강의록·STT fileId) 목록 |
