## 파일

| `crop.py`, `grid.py` | 학습지 페이지 렌더(read_material_pages)에서 사진 자르기 / 선지별 사진 합치기 |

## 규칙(사용자 지정)
- 야마: 학습지 원문·정답 그대로. 의심되면 정답은 그대로 두고 `⚠ 정답 확인 필요` 메모. 같은 문제는 한 카드(킹야), 출제 교수 표시(올해 교수와 다르면 표시).
- 아직 수업 전인 칸은 `(야마 · 수업 전)`.
- 티야: 올해 강의록·STT 기반, 교수님 강조는 STT 근거가 있을 때만, 5지선다·정답 선지 길이 티 안 나게(빌드가 1.6배 넘으면 경고).
- 해설 순서: 📌 티야방 → 🎓 올해 수업 기준 → 📚 학습지 해설.

## 티야 추가하는 법 (강의록·STT가 솜에드에 올라오면)
1. `get_lesson_materials(date, period)` / `read_lesson_bundle`로 강의록·STT 확인(11/5 기준 피부과는 아직 하나도 없음).
2. `q<코드>_<이름>.py`에 `Q = [(영역, 키, 문제, [선지5], 정답번호, 해설, [선지별해설5], 근거, [메모]?)]` 작성(정신과 q 모듈과 같은 형식, 선지는 md5 시드로 섞임).
3. `build_derm.py`의 `QMOD`에 `'L0503': 'q0503_struct'`처럼 추가 → 그 칸 이름에서 `(야마 · 수업 전)`이 빠짐.
4. 야마에 올해 수업 기준 해설을 붙이려면 `yexp*.py`에 `EXP = {'y-묶음-연도': {'cls': '...'}}`.
5. 티야방(Google Docs `1bjZhv2j6BEW2zZszwgnGvcpacEEnFG8jhPwL3j9L1dQ`, 피부과 탭: 남경화·박진·윤석권) 멘트는 `tyb.py`에 `TYB = {키: (담당자, 멘트)}`.
