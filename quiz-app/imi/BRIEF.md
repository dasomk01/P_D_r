# 단원 작업 브리프 (임의입 1-2 문풀 앱, quiz-app/imi)

학습지 한 단원과 그 단원의 수업 STT로 **티야(새 5지선다)**, **야마(학습지 기출 원문)**, **출제경향**을 만든다.
앱은 이비인후과 앱(`/tmp/claude-0/ent/quiz-app/ent`, 참고만)과 같은 형식이다. 참고 예시: 그 폴더의 `q8_fn.py`(티야), `y_fn.py`(야마), `yx_fn.py`(선지별 해설), `yimg_ent.py`(그림), `yexp_ent.py`(🎓 올해 수업 기준).

## 자료 (Somed MCP – ToolSearch "+Somed" 로 불러온다)
- STT: `mcp__Somed__read_material_text(fileId, startChar, maxChars=80000)` – **nextStart 가 없어질 때까지 끝까지** 읽는다. 일부만 읽고 다 읽었다고 하지 마라.
- 강의록: `get_lesson_materials(date, period)` 의 kind=강의록 파일. 표·그림·숫자는 `read_material_pages`(페이지 이미지)로 확인. 9/2–10/8 수업은 Somed에 강의록이 없다 → STT 머리말의 「대조 강의록」 Google Drive 링크가 있으면 Google Drive 도구(ToolSearch "+Google_Drive")로 읽어 보고, 못 읽으면 「강의록 없음」.
- 학습지: `mcp__Somed__read_material_pages(fileId="workbook:7f7ac90a-e031-4fbe-9cb0-3b866263c049:<시작>:<끝>", startPage=<1부터, 범위 안 상대쪽>, pageCount=3)` – nextPage 가 없을 때까지 **단원 전 쪽**을 본다. 각 쪽 이미지는 결과의 `[Image: source: …jpg]` 경로에 저장돼 있다(그림 자를 때 씀).
  학습지 쪽: 맨 앞 쪽 = 연도·교수 표. 문항은 「객N./주N.」 + [연도] + 선지 + 표(번호·정답·복원자·참고·담당교수·해설).

## 근거 우선순위 (가장 중요)
1 교수님이 수업 중 강의록을 짚으며 정정한 것(STT) > 2 강의록 > 3 수업 설명(STT) > 4 학습지.
- 교수님이 「넘어가겠다/몰라도 된다/시험 안 낸다」 → 근거 메모에 STT 원문과 시각.
- 「꼭/시험에 낸다/중요하다」 → 따로 표시(티야 해설·출제경향에).

## 만들 파일 (모두 `quiz-app/imi/` 안, 파일 이름의 <slug> = 내 단원 slug, 예: u12_cxr)
키·묶음 이름 앞에는 **단원 코드**(아래 표의 code, 예: cxr)를 붙여 다른 단원과 겹치지 않게 한다.

1. `q<NN>_<code>[_a|_b…].py` – **수업 하나당 하나**의 티야 모듈(NN=단원 번호 2자리).
   ```python
   SEC=('9/2 7교시 · 국소마취·봉합술','정연준')   # (섹션명, 교수)
   S='STT 9/2 7교시(정연준) [통합 전사] 국소마취·봉합술'
   Q=[
   ('티야','la-01','문제',['정답 선지','오답','오답','오답','오답'],1,'해설(교수님 말 인용 포함)',['정답 – 왜','왜 틀림','…','…','…'],S+' 05:12 · 강의록 p.7'),
   ]
   ```
   - 형식 `(영역, 키, 문제, [선지5], 정답번호, 해설, [선지별 해설5], 근거)`. **정답은 항상 1번 자리, 정답번호 1**(빌드가 md5 시드로 섞는다).
   - 수업 하나당 STT 전체를 다 읽고 **15–25문항**(STT 길이에 맞게). 교수님이 강조한 것 위주.
   - **정답 선지가 길이로 티 나면 안 됨**: 정답 길이 ≤ 1.6 × (가장 긴 오답) 이어야 하고, 실제로는 비슷한 길이로 맞춰라.
   - 근거에 **STT 시각**과 (있으면) **강의록 쪽수**.
   - 형성평가(수업 끝 퀴즈) 원문이 자료에 있으면 영역 '형성평가', 키 `<code>-fh-1`…, 원문 선지 순서 그대로, 근거 문자열에 「원문」 포함 → `fq_<slug>.py` 에 `FQ={'<티야 모듈명>':[튜플…]}`. 형성평가는 출제경향 근거로 쓰지 않는다.
2. `y_<code>.py` – 야마(학습지 기출) **원문·정답 그대로**, 학습지 순서대로.
   ```python
   S='<code>'   # 구역 이름
   Y=[ (S,'<code>-hu',2025,'객15','문제 원문',['선지1',…],[1],'학습지 해설 요약',[메모…],'진공용'), … ]
   ```
   - 튜플 `(구역, 묶음, 연도, '객N'/'주N', 문제, [선지], [정답번호…], 학습지 해설 요약, [메모], 출제교수)`.
   - 묶음(fam) = 같은 내용 문제끼리 같은 이름(여러 해 반복이면 킹야/킹킹야가 자동 계산됨). 문제·정답 None = 바로 앞 카드와 같은 문제(해만 추가). 문제만 None = 문제·선지 같고 정답이 다른 해.
   - 선지 [] = 주관식(정답 칸에 [] 두고 학습지 답은 해설 요약에). 정답 [] (선지 있음) = 확인 필요/채점 제외.
   - **해석이 갈리는 문항**: 정답을 단정하지 말고 `[]`(채점 제외)로 두고 메모에 「⚖️ 해석 A: … / 해석 B: …」 둘 다.
   - **모든 야마 정답을 강의록·STT로 다시 점검** → 메모에 `'🔎 강의록·수업 점검: …(근거: 강의록 p.x / STT mm:ss)'`. 학습지 정답은 **절대 바꾸지 않는다**. 틀렸다고 판단되면 **강의록 페이지 이미지와 STT를 실제로 확인한 뒤에만** `ansfix_<slug>.py` 에 `F={'y-<fam>-<연도>':([의견상 답],'사유+근거')}` (빌드는 답을 안 바꾸고 ⚠️ 주의 노트로만 보여 줌) (카드키는 `y-<fam>-<첫 연도>`, 같은 fam·같은 해가 둘이면 `-객N` 이 붙음). 확인 못 하면 「확인 필요」 메모만.
   - **끝나면 학습지 단원 전 쪽과 대조**: 학습지의 객/주 문항 수 = y 튜플 수(합친 해 포함) 확인 → 결과를 보고에 적는다(빠진 문제 0개여야 함).
3. `yx_<code>.py` – 객관식 야마 **선지마다 해설**: `X={('<fam>',연도,'객N'):[(해설,태그),…선지 수만큼]}` (카드의 첫 연도·번호). 태그 `'c'`=🎓올해 수업(강의록·STT), `'w'`=📚학습지에만, `'k'`=🧠수업 외 지식. 정답 선지 해설은 「정답 – …」.
4. `yexp_<code>.py` – `CLS={'<fam>':'교수님(날짜): STT에서 직접 확인한 강조'}`, `EXP={}` (선택).
5. 그림 문항: 학습지 쪽 이미지에서 그림을 잘라 `img/<code>-<이름>.jpg`. `python3 crop.py <쪽 이미지 경로> img/<…>.jpg x0 y0 x1 y1` (여러 칸이면 좌표를 이어서). **원본 화질, 화살표·라벨이 잘리지 않게, 해설 표·글은 빼고**. 자른 뒤 Read 로 열어 확인. `yimg_<code>.py`: `IMG={'y-<fam>-<연도>':['img/…jpg']}`, `NOTE={'y-…':'🖼 그림: 학습지 p.N'}`. 원 그림이 없는 해는 같은 문제 다른 해 그림을 쓰고 NOTE 에 「🖼 그림은 20xx년 같은 문제 것(학습지 p.N)」. 티야에 그림이 필요하면 같은 IMG 에 티야 키(`<code>-07`)로 넣어도 된다. **「그림 문항인데 그림 없는 카드 0개」**를 확인해서 보고.
6. `sec_<slug>.py` – 등록:
   ```python
   MODS=['q12_cxr']             # 이 단원 티야 모듈(수업 순서)
   YMODS=['y_cxr']
   YSEC={'cxr':'q12_cxr'}       # 야마 구역 → 그 뒤에 붙일 티야 모듈
   YSRC={'cxr':'「가슴 X-선」 155–179쪽'}
   ```
7. 출제경향: 교수님이 STT에서 **시험을 어떻게 낼지 직접 말한 부분**(「시험에 낸다」, 「이런 식으로 나온다」, 「야마」, 「티야」, 「몰라도 된다」 등)을 `출제경향_<slug>.md` 에 원문 인용 + STT 시각으로. 그걸 근거로 예상문제 3–8개를 `trend_<slug>.py` 의 `Q=[튜플…]`(티야와 같은 형식, 빌드가 영역 '티야'로 바꿔 그 단원 티야에 합침, 키 `<code>-t01`…, 근거에 「출제경향: …원문… (STT mm:ss)」). 직접 언급이 없으면 md 에 「직접 언급 없음」만 쓰고 Q=[].
